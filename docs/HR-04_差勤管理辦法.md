# 無限股份有限公司 差勤管理辦法

## 第一章 總則

### 第1條（目的）
為規範員工出勤、加班及請假，依工作規則（HR-01）第7條、第13條及第15條訂定本辦法。

## 第二章 出勤

### 第2條（彈性上下班）
1. 上班打卡時間為08:00至10:00之間，員工於打卡後工作滿9小時（含午休1小時）即可下班。
2. 核心工作時間為10:00至16:00（午休12:00至13:00除外），員工應在職。
3. 10:00後打卡者為遲到；未達應下班時間離開者為早退。

### 第3條（打卡與補登）
1. 員工上下班應以門禁卡或人資系統打卡。
2. 忘記打卡者，應於3個工作日內於系統補登並經主管確認，每月以3次為限；超過者依工作規則第20條處理。

### 第4條（遠距工作）
1. 職務性質適合者，經單位主管同意，每週得遠距工作至多2日。
2. 遠距工作日之工作時間、打卡及加班規定與到班日相同，員工應以系統線上打卡。

### 第5條（下班後聯繫）
1. 主管於下班時間原則上不以通訊軟體交辦工作；緊急情況除外。
2. 員工於下班時間依主管指示處理工作者，其實際工作時間計入工作時間，並依第3章申請加班。
3. 員工於下班時間未回覆非緊急訊息者，不得因此受不利處分。

## 第三章 加班

### 第6條（加班申請）
1. 加班應事前於系統提出申請，經單位主管核准。
2. 臨時性加班無法事前申請者，應於次一工作日內補提申請。
3. 加班以30分鐘為計算單位。

### 第7條（加班時數上限）
1. 每日正常工時加延長工時合計不得超過12小時。
2. 每月延長工時不得超過46小時。
3. 經勞資會議同意者，每月延長工時得至54小時，但每3個月合計不得超過138小時。

### 第8條（加班費計算）
加班費以 HR-02 第8條所定時薪為基準，依下列倍率計算：
| 加班類型 | 時段 | 倍率 |
|---|---|---|
| 平日延長工時 | 第1至2小時 | 1又1/3 |
| 平日延長工時 | 第3至4小時 | 1又2/3 |
| 休息日（週六）出勤 | 第1至2小時 | 1又1/3 |
| 休息日（週六）出勤 | 第3至8小時 | 1又2/3 |
| 休息日（週六）出勤 | 第9至12小時 | 2又2/3 |
| 國定假日、特別休假日出勤 | 8小時以內 | 當日工資加倍發給 |
| 國定假日、特別休假日出勤 | 超過8小時部分 | 依平日延長工時倍率另計 |
休息日出勤以實際工作時數計算。

### 第9條（例假日）
例假日（週日）原則上不得出勤，僅於天災、事變或突發事件時得依法使員工出勤，並應加倍發給工資，事後給予補假休息。

### 第10條（補休）
1. 員工得於加班申請時選擇領取加班費或補休，公司不得強制員工選擇補休。
2. 補休時數依實際加班時數1:1換算。
3. 補休應於加班之日起6個月內休畢；期限屆滿或離職時未休畢者，依加班當時之倍率發給加班費。

## 第四章 特別休假

### 第11條（特休天數）
員工於同一雇主繼續工作滿一定期間者，依下列規定給予特別休假：
| 年資 | 特休天數 |
|---|---|
| 6個月以上1年未滿 | 3日 |
| 1年以上2年未滿 | 7日 |
| 2年以上3年未滿 | 10日 |
| 3年以上5年未滿 | 每年14日 |
| 5年以上10年未滿 | 每年15日 |
| 10年以上 | 每1年加給1日，加至30日為止 |

### 第12條（計算方式）
本公司特休採「週年制」，以員工到職日為計算基準，每屆滿上表年資時給予新年度特休。

### 第13條（排定）
1. 特休日期由員工自行排定，最小請假單位為1小時。
2. 公司基於急迫之業務需求，得與員工協商調整日期，但不得拒絕員工使用特休。

### 第14條（未休畢之處理）
1. 特休年度終結時未休畢之日數，員工得選擇：
   - 遞延至次一年度使用；或
   - 結算發給工資。
2. 遞延之日數於次一年度終結時仍未休畢者，公司應發給工資。
3. 離職時未休畢之特休，一律結算發給工資。
4. 結算工資以年度終結或契約終止前最近1個月之日薪計算。

## 第五章 請假

### 第15條（假別一覽）

| 事假 | 每年14日 | 不給薪 | 免附 |

| 普通傷病假（住院） | 2年內合計不超過1年（與未住院合計） | 30日內半薪，逾30日不給薪 | 住院證明 |

### 第16條（育嬰留職停薪）
1. 員工任職滿6個月後，於每一子女滿3歲前，得申請育嬰留職停薪，期間至該子女滿3歲止，最長不得逾2年。
2. 自2026年1月1日起，員工得以「日」為單位申請育嬰留職停薪，每一子女合計不得超過30日，併入前項2年期間計算。
3. 以月為單位申請者，應於10日前以書面提出；以日為單位申請者，應依育嬰留職停薪實施辦法所定期限提出。
4. 留職停薪期間，員工得依就業保險法申請育嬰留職停薪津貼及政府薪資補助；公司不得因員工申請育嬰留職停薪而給予不利處分。
5. 留停期滿復職時，公司應回復其原職務；確有困難者，應經員工同意調任相當職務。

### 第17條（哺乳時間）
子女未滿2歲須親自哺乳者，除午休外每日另給哺乳時間60分鐘，視為工作時間。

### 第18條（請假程序）
1. 請假應事先於系統申請，經單位主管核准。
2. 因急病或緊急事故無法事先請假者，應於當日上班時間前以電話或通訊軟體通知主管，並於返回工作後3個工作日內補辦手續。
3. 除另有規定外，請假最小單位為1小時。
4. 未依規定請假而擅離職守者，以曠職論。

### 第19條（病假之保障）
員工1年內請普通傷病假未超過10日者，公司不得因此給予不利處分；超過10日者，人事考核亦不得以請病假為唯一依據。

## 第六章 出差

### 第20條
員工因公出差，交通、住宿依實報實銷，國內出差每日另給膳雜費800元；國外出差依公司國外出差標準辦理。出差期間逢休息日或國定假日搭乘交通工具或執行職務者，依第3章計算加班。

## 第七章 附則

### 第21條
本辦法未規定事項，依勞基法、勞工請假規則、性別平等工作法及相關法令辦理。本辦法經總經理核定後公告施行，修正時亦同。
